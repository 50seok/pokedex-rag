# 데이터 출처

| 파일 | 출처 | 비고 |
|---|---|---|
| `pokemon.json` | [PokeAPI](https://pokeapi.co/) (`pokemon-species`, `pokemon`) | `PokeApiCollector`로 자동 수집. 한국어 이름·분류·도감설명 포함 |
| `kanto-towns.json` | 직접 작성 (namu.wiki 교차 확인) | PokeAPI에 마을 한국어명·서사 정보 없음 |
| `kanto-gyms.json` | 직접 작성 (namu.wiki 개별 체육관 문서 교차 확인) | 관장·타입은 **1세대(레드/그린/블루) 기준**. 연분홍·상록 체육관은 2/4세대에서 관장이 바뀜(독수→도희, 비주기→그린) |
